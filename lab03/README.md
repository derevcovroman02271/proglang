Тип - атрибут объекта данных, задающий множество допустимых значений и методы для работы с ними.

Статическая типизация - свойство языка, при котором тип объекта данных определяется в момент трансляции.

Динамическая типизация - свойство языка, при котором тип объекта данных определяется на этапе выполнения программы в момент создания или присваивания значения.

Неявная типизация - способ определения, при котором тип автоматически выводится транслятором по тексту программы.

Явное преобразование типа - преобразование, которое указано в программе в виде вызова функции или в виде операции.

Неявное преобразование типа - преобразование, которое не указано в программе явно, но транслятор сам подставляет требуемый метод преобразования.

Сильная типизация — язык программирования не содержит (почти
не содержит) правил неявного преобразования типа.

Слабая типизация — язык программирования содержит большое
число правил неявного преобразования типа, допускает каламбуры
типизации.

typedef - дает короткое имя длинному типу. В программе: "typedef unsigned long long ull". Теперь пишу ull вместо unsigned long long.

auto - определяет тип по инициализатору. В программе: "auto x = 5 (int), auto y = 3.14 (double)". Компилятор сам смотрит на правую часть и решает, какой тип.

decltype - определяет тип по выражению в скобках. Нужен когда инициализация не нужна. В программе: "decltype(x) z = 10". Тип z такой же, как и y x, то есть int.

static_cast = преобразование типа на этапе трансляции. В программе: "int i = static_cast<int>(d)". Явно превращаю double в int. Дробная часть отсекается, компилятор не ругается, потому что преобразоване указано явно.

sizeof - оператор, дающий размер в байтах. В программе: "sizeof(int), sizeof(a)" - показывает сколько байт занимает тип или переменная

### Задание 9 **(2)**

*Проверьте работу логического выражения*
```
x==y==z
```
*в языках* **Python**, **Java**, **C++** *для
целочисленных переменных* **x**, **y**, **z**.
*Объясните результат для каждого из языков.*

*Записанную программу сохраните в папке с номером задания.*

Возьмем x = 1, y = 1, z = 1 и x = 1, y = 1, z = 0

Python (task9_py):
В Python сравнении цепочные. Запись x == y == z означает
  (x == y) and (y == z)
а не ((x == y) == z).
Для x=1, y=1, z=1: True
Для x=1, y=1, z=0^ False

C++ (task9_cpp):
Оператор == левоассоциативный, поэтому x == y == z читается как
  (x == y) == z
Сначала (x == y) дает bool. Дальше по правилу неявного преобразования bool приводится к int: false --> 0, true --> 1. Затем это число сравнивается с z.
Для x=1, y=1, z=1: (1==1)=true, 1==1 --> true --> печатает 1
Для x=1, y=1, z=0: (1==1)=true=1, 1==0 --> false --> печатает 0

Java (task9_java):
== тоже левоассоциативный, (x == y) дает boolean. Но в Java boolean и int несовместимы, поэтому boolean == int - ошибка согласования типов. Программа просто не компилируется. Это как раз показывает, что Java - с сильной типизацией, а С++ со слабой

### Задание 10 **(1))**

*Напишите программу на* **Python** *, демонстрирующую возможность неявного преобразования
строки в логическое значение.*

*Записанную программу сохраните в папке с номером задания.*

В Python у каждого объекта есть логическое значение. Значение false получается, если объект пуст или равен нулю, иначе - true.

Для строки это значит: Пустая строка "" - это false. Непустая строка - это true

В программе:
  s1 = "" --> false
  s2 = "hello" --> true
  s3 = "0" --> true

Проверка через if и через bool дает то же самое.

Итог: строка неявно преевращается в bool в условиях if/while и в логических операциях. Пустая строка - false, непустая - true
